# DUSHIMIMANA Unity Mobile Game

## 🎮 Project Overview

DUSHIMIMANA Unity Mobile Game is a mobile game developed using **Unity and C#**, designed specifically for Android devices. The project focuses on interactive touch-based gameplay, level progression, and a simple user-friendly mobile gaming experience.

The game was developed as part of my Smart Computing studies to apply practical knowledge of **game development, C# programming, Unity, user interaction, game mechanics, and mobile application development**.

## ✨ Features

- 🎮 Touch-based mobile controls
- 🗺️ 5+ playable levels
- 📱 Android mobile support
- 🎯 Interactive gameplay
- 🔄 Level progression
- 🏆 Gameplay objectives and challenges
- 🎨 Custom game environments
- ⚙️ C# scripts for game mechanics
- 📲 Designed and tested for Android devices

## 🛠️ Technologies Used

- **Unity**
- **C#**
- **Android**
- **Unity UI**
- **Visual Studio / VS Code**

## 📱 Target Platform

The game was developed for **Android mobile devices** and tested using a **Samsung Galaxy Note10+**.

## 🎮 Controls

The game uses **touch-based controls** designed for mobile devices.

Players interact with the game through on-screen touch controls to navigate and complete the different levels.

## 🗺️ Game Levels

The game contains **5+ levels**, with each level providing different gameplay challenges and objectives.

Players progress through the game by completing the required objectives and advancing to the next level.

## 🚀 How to Play

1. Download the Android APK.
2. Install the game on an Android device.
3. Launch the application.
4. Use the touch controls to interact with the game.
5. Complete the objectives of each level.
6. Progress through all available levels.
